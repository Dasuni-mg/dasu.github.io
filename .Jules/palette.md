## 2024-05-28 - [Accessibility & Feedback Enhancements]
**Learning:** Adding a "Skip to Content" link is a simple but high-impact accessibility win for keyboard users in landing pages with many navigation links. Additionally, visual feedback like a loading spinner on form submission reduces uncertainty during async-like operations (even if using a simple form service).
**Action:** Always include skip-links and form loading states as baseline UX/a11y requirements for static sites.
