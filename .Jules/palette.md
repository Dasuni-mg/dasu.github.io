## 2026-06-24 - Leveraging Framework Utilities for A11y
**Learning:** In projects using CSS frameworks like Bootstrap, standard accessibility patterns (like 'Skip to Content' links) often have pre-defined utility classes ('sr-only', 'sr-only-focusable'). Utilizing these is preferable to adding custom CSS, as it maintains consistency with the design system and avoids unnecessary code bloat.
**Action:** Always audit existing framework CSS files for utility classes before implementing custom styles for common UX patterns.
