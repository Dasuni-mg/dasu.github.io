# Palette's UX Journal

## 2025-05-29 - [Skip to Content Link]
**Learning:** For keyboard and screen reader users, navigating through a long list of menu items on every page load can be tedious. A "Skip to Content" link provides a shortcut to the main content, improving navigation efficiency.
**Action:** Always implement a "Skip to Content" link as the first focusable element in the DOM for portfolio sites or any site with significant navigation.
