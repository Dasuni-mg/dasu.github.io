## 2025-05-14 - Enhancing Accessibility with Skip Links and ARIA States
**Learning:** Even modern-looking portfolios can lack basic keyboard accessibility. A "Skip to Content" link is a critical micro-UX for keyboard users, and syncing ARIA states for mobile menus ensures screen reader users understand the interface's current state.
**Action:** Always check for a skip link and ARIA attributes on interactive components (like hamburger menus) in static HTML projects.
