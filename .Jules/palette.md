## 2025-05-15 - [Skip to Content Link & Semantic Structure]
**Learning:** For single-page portfolio sites with sticky navigation, a "Skip to Content" link is essential for keyboard users to bypass repetitive navigation. Additionally, using `scroll-padding-top` on the `html` element ensures that section headings are not obscured by the sticky navbar when navigating via anchor links.

**Action:** Always include a skip link as the first focusable element in the body and use semantic `<main>` tags to define the primary content area. Apply `scroll-padding-top` equal to the header height for a smoother anchor link experience.
